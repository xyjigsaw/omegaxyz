iDevTools 隐私政策

最后更新日期：2026 年 6 月 20 日

欢迎使用 iDevTools（以下简称“本应用”）。iDevTools 是一款面向 iPadOS 与 iOS Safari 的轻量级网页开发者检查工具，用于帮助用户在 Safari 内检查网页结构、网络请求、Cookie、Storage、控制台输出、页面资源与基础审计信息。

本应用非常重视用户隐私与数据安全。本隐私政策说明本应用可能访问哪些信息、这些信息如何被使用，以及你可以如何管理相关权限。

使用本应用即表示你理解并同意本隐私政策中的内容。

一、信息收集说明

iDevTools 的设计目标是在本地设备上提供网页调试与检查能力。

本应用默认不会主动收集、上传、出售或共享你的个人身份信息，也不会将调试数据上传至开发者服务器。

二、网页内容与开发者检查数据

为了实现网页检查功能，本应用可能在用户主动启用并使用 Safari 扩展或相关调试功能时，访问当前网页中的部分内容和运行状态，包括但不限于：

  • 页面 HTML 结构、DOM 节点、元素属性与内联样式
  • 页面中加载的脚本、样式、图片和其他资源信息
  • 控制台日志、警告、错误与用户执行 JavaScript 命令后的结果
  • 网络请求列表、请求头、响应信息、时间线与瀑布流数据
  • Cookie、localStorage、sessionStorage 以及其他浏览器存储数据
  • robots.txt、sitemap 等快速审计结果

上述信息仅用于在本应用界面中展示、检查、复制或辅助调试网页。除非你主动在网页本身、第三方服务或系统分享功能中提交信息，本应用不会将这些调试数据发送给开发者。

三、Cookie 与 Storage 访问说明

本应用可能读取当前网页可访问范围内的 Cookie 与 Storage 数据，用于：

  • 在调试面板中展示 Cookie 与本地存储内容
  • 帮助用户复制单条或全部 Cookie / Storage 数据
  • 辅助用户排查登录状态、会话状态、缓存和本地配置问题

重要说明：

  • Cookie 与 Storage 数据默认仅在本地设备中处理
  • 本应用不会主动上传这些数据至开发者服务器
  • 复制、分享或粘贴相关数据属于用户主动操作，请注意其中可能包含敏感信息
  • 第三方网站自身如何处理 Cookie 与 Storage 数据，受该网站自身隐私政策约束

四、控制台与 JavaScript 执行说明

本应用可能提供控制台功能，允许用户在当前网页上下文中执行 JavaScript 命令。

执行命令可能会读取或修改当前网页状态，也可能触发网页自身的网络请求、存储写入或第三方脚本行为。请仅在你信任并有权限调试的网页中执行命令。

本应用不会将控制台输入或执行结果主动上传给开发者。

五、网络请求与页面审计说明

本应用可能展示当前网页产生的网络请求信息，包括请求地址、请求头、响应信息、状态码、耗时和资源类型等。

当你使用 robots.txt、sitemap 或类似快速审计功能时，本应用可能会向当前网站或你指定的网站发起必要请求，以获取对应文件并显示检查结果。相关请求会发送到目标网站，而不是开发者服务器。

六、本地数据存储

为了提升使用体验，本应用可能在本地设备保存少量设置或状态信息，包括但不限于：

  • 面板位置、尺寸与布局偏好
  • 明暗模式或界面偏好
  • 用户自定义的调试设置
  • 临时调试状态或最近使用记录

这些数据默认仅保存在用户设备中。你可以通过系统设置、应用内设置或卸载应用来清除相关本地数据。

七、数据共享与第三方服务

本应用默认不会向第三方出售、出租、共享或传输用户个人数据。

当你检查第三方网页时，该网页本身可能加载第三方脚本、广告、统计或其他服务；这些行为由被访问网站及其第三方服务提供方控制，不属于本应用的数据收集行为。

如果未来本应用接入崩溃分析、统计分析或其他第三方服务，本隐私政策将同步更新，并在适当位置说明相关数据处理方式。

八、儿童隐私

本应用面向开发者、设计师与技术用户，不会主动收集儿童个人信息。

九、隐私政策更新

我们可能根据功能更新、平台规则或法律法规要求对本隐私政策进行修改。

更新后的版本将在应用内或相关页面发布。
